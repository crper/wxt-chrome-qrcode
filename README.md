# Quick QRCode - 快速二维码生成器

一个基于WXT + React开发的浏览器扩展，用于快速生成和自定义二维码。

## 功能特点

- 🚀 快速生成二维码：支持文本、链接、选中文本等内容
- 🎨 自定义样式：支持调整大小、颜色、边距等参数
- 🖼️ Logo添加：支持在二维码中心添加自定义Logo
- 💾 多格式导出：支持PNG、JPG、WebP等格式导出
- 🌐 跨浏览器支持：基于WXT构建，支持主流浏览器
- 🔄 实时预览：所有修改都能即时预览

## 使用说明

1. 点击扩展图标打开二维码生成器
2. 输入或粘贴需要生成二维码的内容
3. 使用配置面板自定义二维码样式
4. 选择导出格式并下载

### 快捷操作

- 右键菜单：选中文本后右键可直接生成二维码
- 页面链接：点击链接右键可生成当前链接的二维码

## 开发相关

本项目使用以下技术栈：

- WXT (Web Extension Tools)
- React
- TypeScript
- Tailwind CSS
- Zustand (状态管理)

### 本地开发

```bash
# 安装依赖
pnpm install

# 开发模式
pnpm dev

# 构建生产版本
pnpm build
```
